# Телефонный справочник: задача 1 (консольное приложение, без Qt)

Телефонный справочник на C++17. Контакты сохраняются в текстовом файле в кодировке UTF-8. Весь пользовательский ввод проверяется с помощью регулярных выражений.

## Возможности

- Добавление, редактирование (любого поля) и удаление контактов
- Сортировка по любому полю (по возрастанию / по убыванию)
- Поиск сразу по нескольким полям (без учёта регистра, латиница и кириллица)
- Неограниченное количество телефонных номеров для каждого контакта с указанием типа: рабочий (`work`), домашний (`home`), служебный (`service`)

## Хранимые поля

| Поле | Обязательное |
|---|---|
| Имя, фамилия | да |
| E-mail | да |
| Хотя бы один номер телефона | да |
| Отчество, адрес, дата рождения | нет |

## Правила валидации (`Validator`)

- **Имена (ФИО)**: буквы (латиница или кириллица), цифры, дефис `-` и пробел; должно начинаться с буквы; не может начинаться или заканчиваться на `-`; начальные и конечные пробелы удаляются.
- **Телефон**: `+78121234567`, `88121234567`, `+7(812)1234567`, `8(812)1234567`, `+7(812)123-45-67`, `8(812)123-45-67`. Сохраняется в нормализованном виде `+7XXXXXXXXXX`.
- **Дата рождения**: `ДД.ММ.ГГГГ`, реальная календарная дата (месяц 1–12, количество дней в месяце, високосные годы), строго раньше сегодняшнего дня.
- **E-mail**: `user@domain`, только латинские буквы и цифры (в домене допускаются точки между частями); пробелы вокруг `@` удаляются.
- **Адрес**: буквы, цифры, пробелы и символы `. , / # ( ) № -`.

## Архитектура

| Класс | Роль |
|---|---|
| `Contact`, `PhoneNumber`, `Date` | Модель данных |
| `Validator` | Все регулярные выражения; очистка и нормализация ввода |
| `IContactStorage` | Абстрактный интерфейс хранилища |
| `FileStorage` | Хранение в текстовом файле (один контакт на строку, разделитель — табуляция) |
| `PhoneBook` | Бизнес-логика: добавление / редактирование / удаление / сортировка / поиск, финальная валидация |
| `ConsoleUI` | Текстовое меню |

Класс `PhoneBook` работает только через интерфейс `IContactStorage`, поэтому при необходимости можно добавить другое хранилище (например, базу данных) без изменения основной логики.

## Сборка и запуск

Требования: компилятор с поддержкой C++17, CMake >= 3.16.

    cd task1
    cmake -S . -B build
    cmake --build build
    ./build/phonebook            # файл данных: data/contacts.txt
    ./build/phonebook my.txt     # пользовательский файл данных

В Windows при использовании MinGW добавьте `-G "MinGW Makefiles"` к первой команде `cmake`.

## Тесты

    ./build/validator_tests
    ./build/phonebook_tests

## Формат файла данных

Один контакт на строку, 8 полей, разделённых символом табуляции (`TAB`):
`id, имя, фамилия, отчество, адрес, e-mail, дата рождения, телефоны`.
Телефоны записываются в формате `тип:номер` через `;`. Символы табуляции, переноса строки и обратной косой черты внутри полей экранируются.
